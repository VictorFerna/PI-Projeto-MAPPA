# Random Joke Generator

Exemplo simples de gerador de piadas que consome a API pública JokeAPI (https://v2.jokeapi.dev).

Como usar

1. Abra `index.html` no navegador (pode abrir diretamente como arquivo local) ou hospede em um servidor estático.
2. Clique em "Gerar piada" para buscar uma piada aleatória.

Observações
- A API utilizada: https://v2.jokeapi.dev/joke/Any
- Aplicamos blacklist de conteúdo explícito e sensível por padrão.
- Se preferir um backend/proxy (para evitar limitações de CORS em alguns hosts), posso adicionar um servidor Node.js simples.
